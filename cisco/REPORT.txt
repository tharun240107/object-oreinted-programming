1.VLAN

Procedure:
Physical Setup: Place 2 switches and 8 PCs in the workspace. Connect the switches together using a Cross-Over cable on FastEthernet0/1. Connect the PCs to the switches using Straight-Through cables.

IP Addressing: Assign IP addresses to the PCs.

CSE VLAN (192.168.10.0/24): PC0 (192.168.10.1), PC1 (192.168.10.2), PC4 (192.168.10.3), PC5 (192.168.10.4)

CAI VLAN (192.168.20.0/24): PC2 (192.168.20.1), PC3 (192.168.20.2), PC6 (192.168.20.3), PC7 (192.168.20.4)

Configure Switch 3: Enter the CLI and create VLANs 10 and 20. Assign access ports to the respective VLANs. Set the port connected to Switch 4 as a Trunk port.

bash
Switch> enable
Switch# configure terminal
Switch(config)# vlan 10
Switch(config-vlan)# name CSE
Switch(config-vlan)# exit
Switch(config)# vlan 20
Switch(config-vlan)# name CAI
Switch(config-vlan)# exit
Switch(config)# interface range fa0/2-3
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 10
Switch(config)# interface range fa0/4-5
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 20
Switch(config)# interface fa0/1
Switch(config-if)# switchport mode trunk
Configure Switch 4: Repeat the same VLAN creation and port assignment steps as Switch 3 for the right-side PCs. Set Fa0/1 as a Trunk port.

Testing:

Same VLAN (Should Work): Ping from PC0 (CSE) to PC4 (CSE). The ping should be successful.

Different VLAN (Should Fail): Ping from PC0 (CSE) to PC2 (CAI). The ping should fail (Request Timed Out).

2.Setting Up HTTP and HTTPS Services and Testing Connectivity

Procedure:
Physical Setup: Place a Server and a PC in the workspace. Connect the PC's FastEthernet0 to the Server's FastEthernet0 using a Copper Straight-Through cable.

IP Configuration:

Server: IP: 192.168.1.2, Subnet Mask: 255.255.255.0

PC: IP: 192.168.1.3, Subnet Mask: 255.255.255.0

Enable HTTP/HTTPS Services:

Click on the Server > Services tab > HTTP.

Turn HTTP and HTTPS services to On.

Manage Files (Optional): Edit the index.html file to display a custom message (e.g., "Welcome to my Server").

Testing Connectivity:

Click on the PC > Desktop > Web Browser.

Type http://192.168.1.2 in the URL bar and press Enter.

The web page should load successfully. Repeat for https://192.168.1.2.


3.onfiguring FTP Service and Uploading/Downloading Files
Procedure:
Physical Setup: Connect the Server, PC1, and PC2 to the Switch using Straight-Through cables.

IP Configuration:

Server: IP: 192.168.1.2

PC1: IP: 192.168.1.3

PC2: IP: 192.168.1.4

Enable FTP Service on Server:

Go to Server > Services > FTP.

Turn the FTP service On.

User Setup: Username: sashank, Password: 1234.

Permissions: Check Read, Write, Delete, Rename, and List.

Click Add and then Save.

Testing FTP (Upload):

On PC1, open the Command Prompt.

Type ftp 192.168.1.2 and login with sashank / 1234.

Create a file on PC1 using the Text Editor (e.g., test.txt).

In the FTP prompt, type put test.txt to upload the file.

Type dir to verify the file is now on the server.

4.Setting Up DNS (Domain Name System) Service
Procedure:
Physical Setup: Connect Server, PC1, and PC2 to the Switch.

IP Configuration:

Server: IP: 192.168.1.2, DNS Server: 192.168.1.2

PC1: IP: 192.168.1.3, DNS Server: 192.168.1.2

PC2: IP: 192.168.1.4, DNS Server: 192.168.1.2

(Ensure HTTP is turned On in the Server's Services tab for testing).

Configure DNS Service:

Go to Server > Services > DNS.

Turn the DNS Service On.

Add Record: Name: www.mycompany.com, Type: A Record, Address: 192.168.1.2.

Click Add and Save.

Testing DNS:

On PC1, open the Command Prompt.

Type ping www.mycompany.com. The ping should resolve to 192.168.1.2 and reply successfully.

Open the Web Browser on PC1 and type http://www.mycompany.com. The web page should load.


5.Experiment 5: Analyzing TCP and UDP Protocols
Procedure:
Physical Setup: Connect Server, PC1, and PC2 to the Switch.

IP Configuration: Assign IPs (Server: 192.168.1.2, PC1: 192.168.1.3, PC2: 192.168.1.4). Set DNS Server to 192.168.1.2 on all devices.

Enable Services: Turn On HTTP and DNS on the Server. Add a DNS A Record for www.test.com pointing to 192.168.1.2.

Prepare Simulation Panel:

Switch to Simulation Mode.

Click Edit Filters and uncheck STP, CDP, and DTP (background noise).

Ensure DNS, HTTP, TCP, and UDP are checked.

Generate UDP Traffic (DNS):

On PC1, open Command Prompt and type ping www.test.com.

In the Simulation Panel, locate the DNS packet.

Double-click the packet to open the PDU Information window. Expand Layer 4 and observe UDP.

Generate TCP Traffic (HTTP):

On PC1, open the Web Browser and navigate to http://www.test.com.

In the Simulation Panel, locate the first TCP packet.

Double-click the packet. Expand Layer 4 and observe TCP.

Observe the Sequence Number and Acknowledgment Number fields.

Click Play to observe the 3-Way Handshake (SYN -> SYN-ACK -> ACK).
